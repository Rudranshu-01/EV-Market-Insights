04 · Method

How this project works

The Flask backend reads a compressed CSV dataset with Pandas and computes aggregate summaries. Chart.js renders the website's own interactive charts. Tableau's official embedding library displays the separately published reference dashboard and story. The included Tableau workbook is retained only as an attributed reference.

Technology: Python · Flask · Pandas · HTML · CSS · JavaScript · Chart.js · Tableau Embedding API.
